Scheduling for LLM inference

At the Sky Computing Lab I work on how inference requests get scheduled: when many tenants compete for the same GPUs, who gets served next, and how do you stay fair without wrecking throughput? Below is that question, running live.

Scheduler · 4 workers · fair queuing

Service received

Each block is a request. The scheduler always serves the tenant that has received the least service so far — so when one floods the queue, the others still get through. Add a burst and watch the bars pull back level.
